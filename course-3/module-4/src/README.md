# 💻 Practical Project: Client Portfolio Web Application
# 💻 Proyecto Práctico: Aplicación Web de Portafolio para Cliente

This directory contains the source code for the evaluation project completed in Module 4.

Este directorio contiene el código fuente del proyecto de evaluación completado en el Módulo 4.

---

## 🛠️ Technical Breakdown / Desglose Técnico

### 1. Semantic HTML5 Structure / Estructura Semántica en HTML5
* **English:** Organised content using semantic tags such as `<header>`, `<main>`, `<section>`, and `<footer>` to establish clear document hierarchy. Applied proper image structure with `<img>` wrapped in `<div>` containers, including descriptive `alt` text to ensure web accessibility (a11y).
* **Español:** Estructuración del contenido utilizando etiquetas semánticas como `<header>`, `<main>`, `<section>` y `<footer>` para establecer una jerarquía clara. Se implementó una estructura correcta para imágenes con `<img>` dentro de contenedores `<div>`, añadiendo texto `alt` descriptivo para garantizar accesibilidad web (a11y).

---

### 2. Styling with CSS3 / Estilizado con CSS3
* **English:** Applied custom styling to build a clean layout. Custom CSS classes were used to target and style specific components independently, maintaining separation of concerns and a unified design theme.
* **Español:** Aplicación de estilos personalizados para crear una maquetación limpia. Se utilizaron clases CSS para seleccionar y estilizar componentes de forma independiente, manteniendo la separación de responsabilidades y una identidad visual unificada.

---

### 3. Client-side Logic with JavaScript / Lógica con JavaScript
* **English:** Implemented interactive DOM manipulation for user feedback. Handled form submission events so that when a visitor submits a recommendation or comment, a confirmation modal/message dynamically acknowledges their submission upon clicking the submit button.
* **Español:** Implementación de manipulación interactiva del DOM para retroalimentación al usuario. Se gestionó el evento de envío del formulario para que, cuando un visitante deje una recomendación o comentario, aparezca un mensaje dinámico de agradecimiento al presionar el botón de enviar (*submit*).

---

## 📁 Project Files / Archivos del Proyecto

* 📄 `index.html` - HTML5 semantic layout / Estructura semántica.
* 🎨 `style.css` - Custom CSS stylesheet / Hoja de estilos personalizada.
* ⚡ `script.js` - Dynamic DOM interaction and event handling / Interacción con el DOM y eventos
