# 📖 Module 4: Final Hands-on Project - Client Portfolio Web Application
# 📖 Módulo 4: Proyecto Práctico Final - Portafolio Web para Cliente

## 🎯 Module Objectives / Objetivos del Módulo
Apply HTML5, CSS3, and JavaScript knowledge to design and develop a single-page static portfolio application as a web developer consultant for ABC Consultant firm.

Aplicar conocimientos de HTML5, CSS3 y JavaScript para diseñar y desarrollar un portafolio web estático como desarrollador web para la firma consultora ABC Consultant.

## 💡 Project Overview / Resumen del Proyecto

### English
* **Scenario:** Roleplaying as a web developer at **ABC Consultant**, designing a professional single-page static portfolio for a client to highlight their background, achievements, and skills to employers.
* **Technical Implementation:**
  * Clean semantic HTML5 structure.
  * Custom CSS3 layout, colors, and responsive formatting.
  * JavaScript interactive elements and DOM manipulation.
* **Project Files:** The full evaluation source code is available directly in the [`src/`](./src/) directory of this module.

---

### Español
* **Escenario:** Rol de desarrollador web en **ABC Consultant**, diseñando un portafolio estático profesional de una sola página para un cliente con el fin de destacar su experiencia, logros y habilidades ante empleadores.
* **Implementación Técnica:**
  * Estructura HTML5 semántica y limpia.
  * Maquetación, colores y diseño adaptable con CSS3 personalizado.
  * Elementos interactivos y manipulación del DOM con JavaScript.
* **Archivos del Proyecto:** El código fuente de la evaluación está disponible directamente en la carpeta [`src/`](./src/) de este módulo.
