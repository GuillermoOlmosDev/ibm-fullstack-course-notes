# 📖 Module 1: Getting Started with HTML5, DOM & Scripting
# 📖 Módulo 1: Introducción a HTML5, DOM y Scripting

## 🎯 Module Objectives / Objetivos del Módulo
Understand core HTML5 capabilities, browser rendering concepts, the Document Object Model (DOM), and basic hands-on development using interactive editors.

Comprender las capacidades fundamentales de HTML5, la representación en navegadores, el Modelo de Objetos del Documento (DOM) y el desarrollo práctico básico mediante editores interactivos.

## 💡 Key Takeaways / Puntos Clave Aprendidos

### English
* **HTML5 Foundations:** Evolution, key features, browser support, and differences with other markup languages like XML.
* **Document Object Model (DOM):** How browsers parse HTML into a tree structure that allows dynamic interaction.
* **Scripting Integration:** Enabling JavaScript execution within HTML documents.
* **Hands-on Tooling:** Experimenting with markup, styles, and scripts using JSFiddle and developer tools.

---

### Español
* **Fundamentos de HTML5:** Evolución, características clave, soporte en navegadores y diferencias con otros lenguajes como XML.
* **Modelo de Objetos del Documento (DOM):** Cómo los navegadores interpretan el HTML en una estructura de árbol que permite la interacción dinámica.
* **Integración de Scripts:** Habilitación de la ejecución de JavaScript dentro de documentos HTML.
* **Herramientas Prácticas:** Experimentación con maquetación, estilos y scripts usando JSFiddle y herramientas de desarrollo
