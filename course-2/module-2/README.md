# 📖 Module 2: Cloud Computing Models & Services
# 📖 Módulo 2: Modelos y Servicios de la Nube

## 🎯 Module Objectives / Objetivos del Módulo
Master the core service layers (IaaS, PaaS, SaaS) and deployment models to select the right architectural strategy for technical requirements.

Dominar las capas de servicio principales (IaaS, PaaS, SaaS) y los modelos de despliegue para seleccionar la estrategia de arquitectura adecuada según los requerimientos técnicos.

## 💡 Key Takeaways / Puntos Clave Aprendidos

### English
* **Service Models:**
  * **IaaS (Infrastructure as a Service):** Raw compute, storage, and networking control (e.g., VMs, bare metal).
  * **PaaS (Platform as a Service):** Managed environments for application building and deployment without infrastructure overhead.
  * **SaaS (Software as a Service):** Ready-to-use software applications delivered over the internet.
* **Deployment Models:** Differences, security boundaries, and use cases for Public, Private, Hybrid, and Community clouds.
* **Shared Responsibility Model:** Understanding where provider security ends and customer management begins across each model.

---

### Español
* **Modelos de Servicio:**
  * **IaaS (Infraestructura como Servicio):** Control sobre cómputo, almacenamiento y redes (ej. VMs, servidores dedicados).
  * **PaaS (Plataforma como Servicio):** Entornos gestionados para construir y desplegar aplicaciones sin gestionar infraestructura.
  * **SaaS (Software como Servicio):** Aplicaciones listas para usar entregadas a través de internet.
* **Modelos de Despliegue:** Diferencias, límites de seguridad y casos de uso para nubes Públicas, Privadas, Híbridas y Comunitarias.
* **Modelo de Responsabilidad Compartida:** Entender dónde termina la seguridad del proveedor y dónde empieza la gestión del cliente en cada modelo.
