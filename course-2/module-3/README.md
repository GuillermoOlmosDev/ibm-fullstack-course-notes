# 📖 Module 3: Cloud Infrastructure & Architecture
# 📖 Módulo 3: Infraestructura y Arquitectura de la Nube

## 🎯 Module Objectives / Objetivos del Módulo
Explore the underlying physical and virtual components of cloud infrastructure, including virtualization, storage types, networking, and containers.

Explorar los componentes físicos y virtuales subyacentes de la infraestructura en la nube, incluyendo virtualización, tipos de almacenamiento, redes y contenedores.

## 💡 Key Takeaways / Puntos Clave Aprendidos

### English
* **Compute & Virtualization:** Hypervisors, Virtual Machines (VMs), vs. Bare Metal servers.
* **Cloud Networking & CDNs:** Virtual Private Clouds (VPC), secure subnets, firewalls, and Content Delivery Networks (CDNs) for low latency.
* **Containerization:** Fundamentals of lightweight containers and how they isolate applications compared to traditional VMs.
* **Storage Options:**
  * **Block Storage:** High-performance, dedicated volumes for databases.
  * **Object Storage:** Scalable storage for unstructured data (e.g., S3/Object buckets).
  * **File Storage:** Shared network filesystems (NAS/NFS).
  * **Direct-Attached Storage (DAS):** Fast local storage attached directly to compute nodes.

---

### Español
* **Cómputo y Virtualización:** Hipervisores, Máquinas Virtuales (VMs) y servidores Bare Metal (Dedicados).
* **Redes en la Nube y CDNs:** Redes Privadas Virtuales (VPC), subredes seguras, firewalls y Redes de Distribución de Contenido (CDN) para baja latencia.
* **Contenedorización:** Fundamentos de contenedores ligeros y cómo aíslan aplicaciones en comparación con las VMs tradicionales.
* **Opciones de Almacenamiento:**
  * **Almacenamiento por Bloques:** Volúmenes dedicados de alto rendimiento para bases de datos.
  * **Almacenamiento de Objetos:** Almacenamiento escalable para datos no estructurados.
  * **Almacenamiento de Archivos:** Sistemas de archivos compartidos en red.
  * **Almacenamiento Conectado Directamente (DAS):** Almacenamiento local rápido conectado a nodos de cómputo.
