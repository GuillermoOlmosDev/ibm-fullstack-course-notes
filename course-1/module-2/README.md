# 📖 Module 2: Software Engineer Tools
# 📖 Módulo 2: Herramientas del Ingeniero de Software

## 🎯 Module Objectives / Objetivos del Módulo
Identify and master the core developer ecosystem tools fundamental to a modern software engineering workflow.

Identificar y dominar el conjunto de herramientas (Ecosistema Developer) fundamentales para el flujo de trabajo de un desarrollador de software moderno.

## 💡 Key Takeaways / Puntos Clave Aprendidos

### English
* **Version Control:** Fundamentals of Git and collaborative workflows using GitHub.
* **Development Environments (IDEs):** Setting up and efficiently using Visual Studio Code, extensions, and integrated terminals.
* **Package Managers & Environments:** Introduction to dependency management across tech stacks.
* **Command Line Interface (CLI):** Navigating terminal commands for directory inspection, file management, and script execution.

---

### Español
* **Control de Versiones:** Fundamentos de Git y entornos colaborativos en GitHub.
* **Entornos de Desarrollo (IDE):** Configuración y uso eficiente de Visual Studio Code, extensiones y terminales integradas.
* **Gestores de Paquetes y Entornos:** Introducción a gestores de dependencias en diferentes ecosistemas.
* **Consola de Comandos (CLI):** Manejo de la terminal para navegación, gestión de archivos y ejecución de scripts.
