# 🎓 Course 1: Introduction to Software Engineering / Introducción a la Ingeniería de Software

This directory contains notes, summaries, and key concepts learned during the first course of the **IBM Full Stack Software Developer Professional Certificate** program on Coursera.

## 📌 General Overview / Resumen General
The course covers everything from the theoretical foundations of Software Engineering and the Software Development Life Cycle (SDLC) to development tools, modern architectures, testing methodologies, professional ethics, and career paths.

---

Este directorio contiene las notas, resúmenes y conceptos clave aprendidos durante el primer curso del programa **IBM Full Stack Software Developer Professional Certificate** en Coursera.

El curso abarca desde los fundamentos teóricos de la Ingeniería de Software y el Ciclo de Vida del Desarrollo de Software (SDLC), hasta herramientas de desarrollo, arquitecturas modernas, metodologías de testing, ética profesional y opciones de carrera.
